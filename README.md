# Einwandfrei – Verkaufstrainer

Mobile-first Web-App zum Trainieren von Einwand- und Vorwandbehandlung nach den Prinzipien von Alex Hormozi.

## Stand
- Phase 1: Marke, Grundgerüst, Akademie mit 6 Lektionen und Quiz ✅
- Freitext-Übungen pro Lektion, CLOSER-Praxis (2 Szenarien), Videos pro Lektion ✅
- Phase 2: Einwand- und Vorwand-Bibliothek, Karteikarten
- Phase 3: KI-Rollenspiel mit Feedback
- Phase 4: Login, Fortschritt, Deployment

## Starten
```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # statischer Export nach ./out
```

Inhalte der Lektionen: `lib/lessons.ts`.
